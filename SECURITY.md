# Security policy

Please report vulnerabilities privately to `security@review-to-rule.dev`. Do
not open a public issue until a fix is available. Include affected versions,
reproduction steps, and impact without credentials or private repository data.

The maintainers will acknowledge a report within seven days. Only the latest
released minor version is supported. See [docs/SECURITY.md](docs/SECURITY.md)
for the threat model and trust boundaries.
